Limits:

- TerraDS has no fork flag. A fork that diverged below Jaccard 0.8 in every rule is not detected: how many such forks exist is not yet established.

## Limits

- **Yield (R1).** The checks E05 to E07, E09 and E12 remove many modules; the counts above are the measured yield.
- **Lineage (R3).** TerraDS has no fork flag; forks that diverged below the thresholds are not detected (number: not yet established).
- **Licence text (R4).** TerraDS carries no licence files; each file was fetched from raw.githubusercontent.com at the pinned commit. Repositories deleted since the crawl, or whose file is not one of the six names, are E11.
- **Selection bias (R5).** See the top of this report.
- **Not measured here:** whether DAIL can parse a pooled module (measured later, in the DAIL repository, and never fed back); behaviour of the pooled modules under `terraform plan`; the number of undetected forks.

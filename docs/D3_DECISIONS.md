# D3 decisions

Decisions for the D3 work package (the TerraPreserve real-world pool). `Decided` rows were decided by the user on 30 Oct 2026. `Proposed` rows are the work package's design: they are followed as written, and a row says so if one of them turned out to be wrong. Cells contain no pipe characters, so the table parses mechanically (`tests/test_d3_decisions.py`).

| ID | Decision | Status | Reason | Rests on |
|---|---|---|---|---|
| D3-01 | Licences: permissive only. A repository enters the pool only if `Repositories.License` is in the `permissive` bucket of `sources/terrads/measure_yield.py` (MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, 0BSD, Unlicense, CC0-1.0, Zlib, MIT-0, BSL-1.0). Weak copyleft, strong copyleft and other/unknown (NOASSERTION, null and the nine unmatched strings) are excluded and counted. | Decided | D0 Decision 9 admits only repositories whose licence allows modification and redistribution; copyleft terms would attach to the redistributed modules. Closes `docs/D3_CARRYOVER.md` item 5. | D0 Decision 9; `docs/D3_CARRYOVER.md` items 5 and 7; `sources/terrads/measure_yield.py` (PERMISSIVE) |
| D3-02 | Parser: our own lexical reader only (`sources/hcl_lex.py`, extended by new functions), TerraDS metadata and Terraform's own tooling. No DAIL code, no DAIL parser output, no list of modules DAIL can parse. | Decided | D0 gate 1 and DAIL ADR-010/ADR-013: the benchmark must not be selected by what DAIL can parse. Whether DAIL parses a pooled module is measured later in the DAIL repository and never feeds back. | CLAUDE.md rule 5; `pool/README.md`; `tests/test_independence.py` |
| D3-03 | Native first, graft the rest. Every native module (F3: both `aws_instance` and `aws_db_instance`) that survives the cascade enters the pool; graft hosts (G) fill the remainder. Actual native and host counts are reported; nothing is padded. | Decided | D0 Decision 3: grafting only where a module lacks the EC2-to-RDS path, and "yields are never assumed or padded". | D0 Decision 3 (quoted in the work package, section 3.2) |
| D3-04 | Layout: `pool/terrads/native/<module_id>/` and `pool/terrads/host/<module_id>/` (verbatim `.tf`, `SOURCE.json`, `LICENSE.upstream`), `pool/terragoat/aws/` (17 redacted files, `SOURCE.json`, `REDACTION_LOG.md`, `NOTICE`), plus `pool.json`, `exclusions.csv`, `funnel.json`, `lineages.json`, `licence_checks.csv`, `validate_results.csv`, `POOL_REPORT.md`. Directories are named by TerraDS module id only. Pool `.tf` files are verbatim copies with LF endings; the only edits ever made to third-party text are the logged TerraGoat redactions. | Proposed | Short Windows paths; one stable key per module; verbatim text keeps the per-file licence and hash record honest. | Work package section 3.3; CLAUDE.md rule 9 |
| D3-05 | Candidate sets: native = F3 and permissive; hosts = G and permissive. Flags come from `sources/terrads/candidates.csv` and are recomputed from the pinned database if a column is missing. | Proposed | Reuses the measured funnel levels instead of defining new ones. | `sources/terrads/measure_yield.py` (flags); `sources/terrads/candidates.csv` |
| D3-06 | Exclusion cascade E01 to E12, applied in that order, first matching code recorded. Data sources, count, for_each, dynamic, locals, lifecycle and provisioners are flags, not exclusions. | Proposed | A fixed order makes the ledger reproducible; flags keep unsupported constructs visible instead of dropping them (plan D3 step 2). | Plan D3 step 2; work package section 3.3 table |
| D3-07 | Lineage: connected components under same repository, identical normalised module text, at least 50 percent of files sharing a normalised hash (two or more files), and 5-token shingle Jaccard of at least 0.8 (MinHash with 64 permutations, 16 bands of 4 rows, seeded, confirmed by exact Jaccard). Id is `lin-` plus the smallest repository id, zero-padded to 12 digits. A fork that diverged below 0.8 is not detectable and is reported as not yet established. | Proposed | D0 Decision 7 splits dev and test by repository lineage, so D4 needs reliable lineage ids; TerraDS has no fork flag. | D0 Decision 7; D0 gate 6 |
| D3-08 | Pool entry schema in `pool/pool.json` (canonical JSON, sorted keys): identity, source, licence, lineage, files with hashes, resources, type counts, flags, graft facts, secrets, validate. No scenario fields, labels or safety judgement. The canonical core addresses are a constant list taken from Doc 04 Appendix B as the D2 fixture names them. | Proposed | D3 supplies facts; D4 builds scenarios; D5 labels. | Work package section 3.3 (D3-08) |
| D3-09 | Validation harness (E12): in a temporary directory outside the repository, copy the module, remove every top-level terraform and provider block, add `versions.tf` pinning Terraform `~> 1.15.0` and `hashicorp/aws` 6.53.0, initialise against a local filesystem mirror, run `terraform validate`. The committed pool files stay verbatim; D4 must reproduce the transformation. | Proposed | CLAUDE.md rule 3 pins; D0 gates 2 and 9. | CLAUDE.md rule 3; D0 Decision 10 gates 2 and 9 |
| D3-10 | Processing order: E01 to E08 run on all natives and all permissive G modules; lineages over the survivors; hosts reduced to one per lineage (smallest module id); remaining hosts shuffled with `random.Random(20261030)` over sorted module ids and pushed through E09, E11 and E12 until 400 hosts are accepted or 1,500 processed; the rest is counted as NOT_PROCESSED. All natives pass every step. | Proposed | Bounds network and Terraform time without hiding the unprocessed remainder. | Work package section 3.3 (D3-10) |
| D3-11 | Recorded deviations: (a) the plan's P2 redactor is replaced by gitleaks 8.30.1 plus the attribute inventory; (b) real-world modules with secrets are excluded, not redacted; (c) the reader is a lexical reader, not a parser. | Proposed | CLAUDE.md rule 5 forbids DAIL code; editing third-party text would break verbatim and the licence record. | Plan D3 step 4; CLAUDE.md rules 5 and 6; `sources/hcl_lex.py` docstring |
| D3-12 | TerraGoat (controlled tier): copy the 17 `terraform/aws/*.tf` files at commit 729f8da6 into `pool/terragoat/aws/`; delete the attributes the inventory flags and log file, line, address and attribute name (never a value) with before and after sha256; rescan clean; keep the Apache-2.0 notice. No reshaping into the Appendix B topology here. | Proposed | D0 gate 5 (no secrets) and D0 Decision 9 (TerraGoat-derived files keep their Apache-2.0 notice). | D0 Decision 9; D0 gate 5; `sources/terragoat/secret_scan_summary.md` |

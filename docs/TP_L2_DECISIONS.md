# TP-L2 decisions: oracle labels for the test LLM candidates of the DAIL main run

Decisions for work package TP-L2, the second piece of TerraPreserve v1.1. It labels the test-split LLM candidates that DAIL's main run exported (generation `40e2052b-b489-552d-8c27-88785414a4b1`) with TP-L1's rule, unchanged. TerraPreserve v1.0 (`terrapreserve-v1.0`, `27f0ee4`) stays frozen: no file under `scenarios/` and no v1.0 label changes, and `oracle/` is unchanged (`oracle-1.0`). The test split is private: nothing derived from it (no test id, no label, no count by class or by reason) is in this repository. The labels are written under `$TERRAPRESERVE_PRIVATE` and never committed. Cells contain no pipe characters, so the table parses mechanically.
